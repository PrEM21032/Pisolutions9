# PI 30-Day Engineering Roadmap

Daily loop: inspect, build, test, verify, record evidence, select next task.

1-5 Runtime: durable state interface, restart behavior, idempotency, retries, dead-letter handling, capability-aware tools, orchestration, end-to-end runtime test.

6-10 Intelligence: model provider interface, task routing, structured outputs, output validation, evidence and verification, cost and timeout budgets.

11-15 Tooling: research adapter, data adapter, GitHub adapter, deployment preview adapter, normalized evidence.

16-20 Owner experience: objective ingestion, runtime bridge, live status, outcome API, truth labels, recovery and escalation.

21-24 Operations: scheduled queue, checkpoints, priorities, dependencies, observability, audit trail, health checks, pause/resume.

25-27 Security: capability allowlists, secret boundaries, data minimization, unsafe-action rejection, explicit human approval gates.

28-30 Production: full E2E tests, failure injection, preview deployment, rollback verification, production-readiness gate.

Definition of done: code + automated tests + verified behavior + evidence. Never claim external execution, persistence, model access, deployment, or production readiness without evidence. Stop only for credentials, protected approval, paid activation, legal/financial commitment, or irreversible production action.
